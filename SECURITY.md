# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability or an edge-cache manipulation flaw within this framework, please do **not** open a public GitHub issue. 

Instead, please report the vulnerability privately by contacting the maintainer directly at dominicboban@dominic-boban.com. We will acknowledge your report within 48 hours and work to provide a rapid remediation patch.

### 🗓️ Incident Response SLA Matrix

| Vulnerability Severity | Initial Acknowledgment | Initial Triage Verdict | Patch Target Resolution |
| :--- | :--- | :--- | :--- |
| 🔴 **Critical** | Within 12 Hours | Within 24 Hours | 48 - 72 Hours |
| 🟠 **High** | Within 24 Hours | Within 48 Hours | 7 - 14 Days |
| 🟡 **Medium / Low** | Within 48 Hours | Within 5 Days | Next Scheduled Update |
